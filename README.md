## 📁 Repository Contents

This repository is organized by topic to cover key concepts in structured programming:

* **Basics/** – Fundamental C concepts, basic I/O operations, and data types.
* **if_else/** – Conditional logic and decision-making programs.
* **loop/** – Iterative structures (`for`, `while`, `do-while` loops).
* **Pattern/** – Pattern printing problems using nested loops.
* **Function/** – Modular programming, functions, and parameters.
* **Pointers/** – Direct memory management and pointer arithmetic.
* **recursion/** – Recursive function calls and base cases.
